Medical ChatBot (AI Assistant)
------------------------------
Prereqs:
- Python 3.10+
- pip

1. Copy project to folder
2. Create a virtualenv and activate it
3. pip install -r requirements.txt
4. Create a .env file containing:
   OPENAI_API_KEY=sk-...

5. Run:
   python app.py
6. Open http://127.0.0.1:5000 in your browser

Notes:
- This tool gives general guidance only. Do not use as a substitute for professional medical care.
- Triage rules sourced from NHS, CDC, Mayo Clinic, Johns Hopkins.
